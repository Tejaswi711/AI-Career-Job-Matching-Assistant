# AI-Powered Career & Job Matching Assistant

An AI-powered chatbot that helps job seekers with career guidance, job description analysis, skill-gap identification, resume improvement, learning recommendations, and interview preparation.

##  Project Overview

Finding the right job can be difficult for freshers because they may not know whether their skills match a job requirement or what skills they need to improve.

The **AI-Powered Career & Job Matching Assistant** provides personalized career support through a conversational AI interface.

Users can ask questions about careers, job roles, required skills, interview preparation, and job descriptions.

##  Business Problem

Job seekers often spend a lot of time:

- Understanding job requirements
- Comparing their skills with job descriptions
- Identifying missing skills
- Improving their resumes
- Preparing for technical and behavioral interviews
- Finding suitable learning paths

This project aims to reduce this effort by providing these services through a single AI-powered assistant.

##  Features

- AI-powered career chatbot
- Career guidance
- Job description analysis
- Skill matching
- Skill-gap analysis
- Resume improvement suggestions
- Personalized learning recommendations
- Interview preparation
- Conversational memory
- Interactive Streamlit web interface
